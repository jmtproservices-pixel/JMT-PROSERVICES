# JMT Music Label — site indépendant

Site vitrine premium consacré au gospel et à la musique chrétienne.

## Déploiement sur Netlify sans toucher au site passeport

1. Dans Netlify, choisissez **Add new site** puis **Import an existing project**.
2. Connectez GitHub et sélectionnez le dépôt `jmtproservices-pixel/JMT-PROSERVICES`.
3. Créez un **nouveau site Netlify** (ne modifiez pas le site existant).
4. Dans les paramètres de build :
   - **Branch to deploy** : `main`
   - **Build command** : laisser vide
   - **Publish directory** : `music-label`
5. Lancez le déploiement.

Le site d’assistance aux passeports utilise les fichiers à la racine du dépôt. Le site musical utilise uniquement le dossier `music-label`; ne changez pas le répertoire de publication du site passeport.
